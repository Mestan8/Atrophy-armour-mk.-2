# Header image credits

Decorative background images for the header band of each page, applied with CSS
(`body[data-page]` in `assets/css/site.css`). They carry no information, are not
shown with a caption, and are not part of the Study Library or the reference
table. All were chosen so that no on-page credit is required.

Each image was resized to 1920 px wide and re-encoded as WebP with Pillow.
